# سجل طلبات المشروع — دليل عوالم DC

المصدر: محادثة Gemini (١–٩ نوفمبر ٢٠٢٦) + محادثة Claude (١٠ نوفمبر ٢٠٢٦).
الحالة: ⬜ لم يبدأ · 🟡 جزئي في النسخة القديمة · ✅ منجز ومُختبر في النسخة الجديدة.

## أ. المحتوى والبيانات
| # | الطلب | الحالة |
|---|---|---|
| A1 | كل أعمال DC (أفلام، مسلسلات، أنميشن) من أول عمل إلى اليوم | 🟡 181 عملاً — القائمة ناقصة وتحتاج استكمال موثّق |
| A2 | كل مجموعة: متسلسلة أم منفردة، والمتسلسلة بترتيب زمن القصة لا الإصدار | 🟡 |
| A3 | كل عالم/ريميك وأعماله محدَّدة | 🟡 |
| A4 | تقييم النقاد + تقييم الجمهور لكل عمل، وحكم «يستحق المشاهدة؟» | 🟡 أرقام ثابتة غير موثّقة |
| A5 | معلومات محدّثة من النت دائماً (تقييمات وغيرها) | ⬜ |
| A6 | كل تقييم زر يفتح صفحة العمل نفسها في مصدره | 🟡 زر النقاد يفتح صفحة بحث |
| A7 | المسلسلات: عدد المواسم والحلقات، ولكل حلقة صورتها واسمها وتقييمها ومعلوماتها | 🟡 |
| A8 | آروفيرس: أي موسم/حلقة من أي مسلسل يتبعه أي موسم/حلقة | 🟡 26 مرحلة غير موثّقة، وعليها تقييمات لا مصدر لها |
| A9 | الأعمال القادمة المعلنة آخر كل عالم + تاريخها + عدّاد تنازلي، وتنتقل للخط الزمني تلقائياً عند الصدور | ⬜ |
| A10 | الدليل صحيح ١٠٠٪ قدر الإمكان، وأي عمل في عالمين يكون موثّقاً رسمياً | 🟡 الثلاثة الحالية موثّقة بمصادرها |

## د. أسلوب العمل
- D1 اختبار فعلي قبل كل تسليم، مع إرفاق النتائج (كمبيوتر + جوال).
- D2 التحقق من المعلومات من مصادر رسمية، وما لم يُتحقق منه يُعلَّم بذلك.
- D3 استباق المشاكل والاحتياجات القادمة.
- D4 الجودة قبل السرعة.
